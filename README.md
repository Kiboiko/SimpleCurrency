# SimpleCurrency

SimpleCurrency - учебный Ruby-проект для лабораторной работы, реализующий Telegram-бота для конвертации валют с локальным кэшированием курсов.

## Цель проекта

- Реализовать Telegram-бота для конвертации валют.
- Использовать внешний API валют и локальный кэш для экономии запросов.
- Обеспечить удобный диалог с пользователем через команды и inline-кнопки.
- Покрыть логику тестами.

## Структура проекта

- bin/bot - точка запуска Telegram-бота.
- lib/simple_currency_bot.rb - логика бота и диалог с пользователем.
- lib/simple_currency_cacher.rb - загрузка курсов, кэш и расчет конвертации.
- spec/simple_currency_bot_spec.rb - тесты поведения бота.
- spec/simple_currency_cacher_spec.rb - тесты конвертера и кэша.

## Как работает бот

1. Бот отправляет приветственное сообщение с кнопками:
   - Конвертировать валюту
   - Показать курсы
   - Помощь
2. Пользователь выбирает конвертацию или просмотр курсов.
3. Бот запрашивает сумму для перевода (при конвертации) или показывает текущие курсы (при выборе "Показать курсы").
4. Пользователь выбирает валюту отправления.
5. Пользователь выбирает валюту назначения.
6. Бот рассчитывает результат и показывает курс.
7. В конце выводятся кнопки:
   - Конвертировать еще
   - Главное меню

### Команды

- /start - открыть главное меню.
- /help - показать справку.
- /convert - начать конвертацию.
- /rates - показать текущие курсы валют.

Быстрый формат конвертации: отправьте сообщение типа "100 $ ₽" для конвертации 100 долларов в рубли. Поддерживаются символы валют ($ € ₽ £ ¥) и коды (USD EUR RUB и т.д.).

## Логика конвертера и кэша

### SimpleCurrencyCacher

- Загружает курсы валют из публичного API.
- Сохраняет кэш в файл ~/.currency_cache.json.
- Если кэш моложе 24 часов - использует локальную копию.
- Если кэш устарел - получает свежие данные.
- Если API недоступен и кэш есть - работает с кэшем.
- Если API недоступен и кэша нет - выбрасывает NetworkError.
- Если указана неизвестная валюта - выбрасывает CurrencyNotFoundError.

### SimpleCurrencyBot

- Управляет состоянием пользователя через @user_states.
- Обрабатывает текстовые сообщения и callback-запросы.
- Поддерживает выбор валют из списка и кнопки управления.
- Позволяет повторить конвертацию и вернуться в главное меню.

## Установка и запуск

Установите зависимости:

bundle install

Запустите бота с токеном:

bundle exec ruby bin/bot YOUR_TELEGRAM_BOT_TOKEN

Для Windows PowerShell:

$env:TELEGRAM_BOT_TOKEN = 'YOUR_TELEGRAM_BOT_TOKEN'
bundle exec ruby bin/bot

## Тесты

Запуск всех тестов:

bundle exec rspec

### Что проверяют тесты

- конвертацию валют между USD, EUR, GBP, RUB и другими;
- обработку ошибки CurrencyNotFoundError для неправильной валюты;
- поведение при отключенном API и наличии/отсутствии кэша;
- логику Telegram-бота: приветственное меню, команды /start, /help, /convert, /rates, callback-кнопки и перевод валют.

## Как защитить лабораторную работу

Проект показывает:

- взаимодействие Ruby-приложения с Telegram Bot API;
- использование inline-кнопок и callback-запросов;
- сохранение пользовательского состояния между шагами диалога;
- работу с внешним API и локальным кэшем;
- модульное тестирование бизнес-логики.
